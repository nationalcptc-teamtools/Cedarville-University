# Sublist3r

Sublist3r automates the collection of subdomain names from public information sources. It supports reconnaissance by combining discoveries that would otherwise require separate searches.

Treat collected names as candidates. Resolve and validate them, record their source, and distinguish historical references from currently reachable services.

Public-source enumeration complements certificate transparency searches, DNS enumeration, and virtual host discovery; it does not replace them.
