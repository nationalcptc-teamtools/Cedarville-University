# XML - GEN

XML represents structured information using elements, attributes, and text. Elements can be nested to describe a document hierarchy.

```xml
<user id="1">
  <name>Example</name>
</user>
```

An XML document must be well-formed: tags must match, elements must nest correctly, and reserved characters must be represented appropriately. Well-formedness and validation against a declared document type are different checks.

XML can describe API messages and documentation. [[Tools/GUI Tools/SoapUI - GEN|SoapUI]] supports SOAP service workflows, while [[Tools/Languages/JSON - GEN|JSON]] provides another commonly used data representation.
