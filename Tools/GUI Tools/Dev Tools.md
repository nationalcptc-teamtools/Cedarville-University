Developer Tools are a powerful option in a browser to see more information about the webpage being served. Dev Tools are divided into separate panels with different purposes.

Inspector
	The Inspector panel shows a live view of what is on the website. This also allows for interacting and editing page elements.

Debugger/Sources
	The Debugger panel allows the user to observe the Javascript source code of the webpage.

Network
	The Network panel can be used to track the external requests a webpage makes. It can reveal the software used to manage the website, especially the interactive components. It can also expose other details that help in enumeration and exploitation.

Storage
	The Storage panel allows the user to view and manage the data a webpage stores in the browser. The data is stored client side, and may contain useful information, especially for understanding the application's authentication, session data, user preference, and other stored values.
