
The Cyber Kill Chain is a framework developed by Lockheed Martin to describe the necessary series of events for a successful cyber attack.

1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation
5. Installation
6. Command and Control
7. Actions on Objectives


This Kill Chain is helpful when designing a methodology for penetration testing or other offensive cyber operations.
