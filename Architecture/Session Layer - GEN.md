# Session Layer - GEN

The Session Layer is layer 5 in the [[Network Layers|OSI model]]. It represents the management of communication sessions between systems.

It sits between the [[Architecture/Presentation Layer - GEN|Presentation Layer]] and [[Architecture/Transport Layer - GEN|Transport Layer]]. A browser login session is an application concept and should not automatically be equated with a distinct OSI implementation layer.
