# Presentation Layer - GEN

The Presentation Layer is layer 6 in the [[Network Layers|OSI model]]. Its conceptual role concerns the representation of data exchanged between systems.

It sits below the [[Architecture/Application Layer - GEN|Application Layer]] and above the [[Architecture/Session Layer - GEN|Session Layer]]. Real implementations do not always expose these roles as separate software components.
