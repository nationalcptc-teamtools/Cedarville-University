# IDS - GEN

An Intrusion Detection System monitors and analyzes events for indications of attacks or policy violations. It supports detection rather than assuming that every observed event is malicious.

Network-based and host-based systems observe different evidence. A network sensor's view depends on the traffic available to it; host monitoring can inspect events on the endpoint.

[[Tools/GUI Tools/Wireshark - GEN|Wireshark]] supports manual packet inspection, while an IDS supplies automated detection capabilities. A [[Architecture/Firewall - GEN|Firewall]] enforces traffic policy, which is a different role from detecting suspicious behavior.
