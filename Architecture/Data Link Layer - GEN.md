# Data Link Layer - GEN

The Data Link Layer provides communication over an individual link. In Ethernet, frames carry link-layer addressing such as a [[Protocols and Notation/MAC Address - GEN|MAC Address]].

[[ARP]] relates IPv4 addresses to local link addresses. Link delivery and IP routing are different operations.

In the [[Network Layers|OSI model]], this is layer 2, between the [[Architecture/Network Layer - GEN|Network Layer]] and [[Architecture/Physical Layer - GEN|Physical Layer]].
