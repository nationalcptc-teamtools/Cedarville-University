# Operating System - GEN

An operating system manages hardware resources and supplies services used by programs. Its responsibilities include execution, storage, input/output, and access to system resources.

Applications run within the facilities and restrictions supplied by the operating system. The kernel is a core component, not necessarily the entirety of the installed environment.

[[Architecture/Unix - GEN|Unix]] describes a related operating-system tradition. [[Linux Users]], [[Linux Groups]], and [[Ports]] cover particular identity and networking concepts used by an operating system.
