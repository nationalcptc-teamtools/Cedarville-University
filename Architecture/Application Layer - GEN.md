# Application Layer - GEN

The Application Layer is layer 7 in the [[Network Layers|OSI model]]. It provides network services used by applications.

Examples include [[Protocols and Notation/HTTP - GEN|HTTP]], [[Protocols and Notation/FTP - GEN|FTP]], and email protocols. Application behavior is carried through lower-layer communication mechanisms.

The next conceptual layer is the [[Architecture/Presentation Layer - GEN|Presentation Layer]].
