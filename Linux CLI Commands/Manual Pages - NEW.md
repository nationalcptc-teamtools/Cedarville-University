# Manual Pages

Manual pages document installed commands, system interfaces, and configuration formats.

```bash
man COMMAND
```

Read NAME for purpose, SYNOPSIS for invocation syntax, and the option descriptions for argument meaning and behavior. Examples and related references can clarify less common uses.

Prefer documentation matching the installed tool when checking a version-sensitive option. A command's `--help` output can provide a shorter syntax reference where supported.
