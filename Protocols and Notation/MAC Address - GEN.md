# MAC Address - GEN

A MAC address identifies a link-layer interface in technologies such as Ethernet. A common representation is a 48-bit value written as six hexadecimal octets.

```text
02:00:00:00:00:01
```

IEEE 802 addressing distinguishes individual/group addressing and universally/locally administered addresses. An address observed on a network should not automatically be treated as a permanent hardware identity.

[[ARP]] maps IPv4 addresses to link-layer addresses on a local link. The [[Architecture/Data Link Layer - GEN|Data Link Layer]] and [[Architecture/Network Layer - GEN|Network Layer]] perform different delivery functions.
