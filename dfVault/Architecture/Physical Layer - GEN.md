# Physical Layer - GEN

The Physical Layer describes transmitting bits through a physical medium, including electrical, optical, or radio signaling and interface characteristics.

It is layer 1 in the [[Network Layers|OSI model]], below the [[Architecture/Data Link Layer - GEN|Data Link Layer]]. Packet contents and application authorization are higher-level concerns.
