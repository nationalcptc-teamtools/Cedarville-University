# Unix - GEN

Unix systems organize interaction around a kernel, command interpreters called shells, and utilities. Files are arranged in a hierarchical directory tree.

The kernel supplies services used by programs. A shell interprets commands and can run sequences stored as [[Scripts]].

[[Linux Users]] and [[Linux Groups]] describe related account concepts used in Unix-like environments. Commands such as [[Linux CLI Commands/id - GEN|id]] and [[Linux CLI Commands/su - GEN|su]] inspect or change the identity context.

The precise interfaces and administration tools depend on the operating system; not every Unix-like environment behaves identically.
