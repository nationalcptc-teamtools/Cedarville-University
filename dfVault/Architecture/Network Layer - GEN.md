# Network Layer - GEN

The Network Layer concerns packet delivery across interconnected networks, including logical addressing and route selection.

IP supplies the corresponding Internet-layer service. [[ICMP]] reports selected control and error information. [[CIDR]] describes address prefixes used in IP networking.

In the [[Network Layers|OSI model]], this is layer 3, between the [[Architecture/Transport Layer - GEN|Transport Layer]] and [[Architecture/Data Link Layer - GEN|Data Link Layer]].
