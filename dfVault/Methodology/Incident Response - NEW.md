# Incident Response

A Computer Security Incident Response Team coordinates the handling of security incidents.

1. **Preparation:** Establish people, processes, tooling, and evidence handling.
2. **Identification:** Determine what happened and which assets are affected.
3. **Containment:** Limit further impact while preserving useful evidence.
4. **Eradication:** Remove the cause and malicious artifacts.
5. **Recovery:** Restore operation and monitor for recurrence.
6. **Lessons learned:** Improve controls and response based on the incident.
