# Java - GEN

Java is a programming language and platform. Java source normally uses `.java` files; `javac` compiles it into `.class` bytecode for the Java Virtual Machine.

```bash
javac Example.java
java Example
```

The Java launcher runs the class through a JVM. A `.class` file is not ordinary native machine code for the local processor.

Java provides classes, objects, methods, and a standard library. The runtime and application dependencies form part of the environment being inspected.
