# Postman - GEN

Postman is an API client for constructing requests, inspecting responses, and organizing API work.

**Request workflow**
---
1. Select a request type and destination.
2. Configure the required method, parameters, headers, and body.
3. Send the request and inspect its response.
4. Save useful requests in a collection.
5. Add response tests when repeatable validation is needed.

Use [[API documentation]] to determine expected inputs and behavior. A valid [[Tools/Languages/JSON - GEN|JSON]] response does not establish correct authorization; inspect the actual returned data during [[API Testing]].
