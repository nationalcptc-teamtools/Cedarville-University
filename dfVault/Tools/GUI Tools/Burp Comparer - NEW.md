# Burp Comparer

Comparer displays differences between two pieces of data at word or byte level. Send requests or responses from another Burp component using **Send to Comparer**, or load and paste data manually.

## Comparison modes

- **Words:** Highlights textual differences such as messages, usernames, or error content.
- **Bytes:** Reveals exact differences in binary data, whitespace, and encoded content.

The comparison window shows the paired inputs, highlights differences, and supports synchronized navigation. Switching representation can make subtle changes easier to inspect.

## Applications

Compare responses for existing and nonexistent accounts, valid and invalid credentials, different object owners, or changed request parameters. Look for stable distinctions in wording, length, headers, or returned data.

Dynamic timestamps, tokens, and unrelated personalization can create noise. Repeat the requests and distinguish security-relevant differences from ordinary variation before drawing a conclusion.
