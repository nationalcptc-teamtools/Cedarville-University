# SoapUI - GEN

SoapUI provides tools for constructing and testing SOAP and REST service requests. Projects organize interfaces, requests, and test cases.

**Typical workflow**
---
- Create a project from an appropriate service definition or endpoint.
- Configure a request and submit it.
- Inspect the response.
- Organize repeatable checks into test cases and assertions.

SOAP workflows commonly use [[Tools/Languages/XML - GEN|XML]] and WSDL definitions. [[API documentation]] explains the intended operations and message structure.

Use [[Tools/GUI Tools/Postman - GEN|Postman]] as another API client option when comparing workflows. Tool support does not replace checking the server's actual authentication and authorization behavior.
