# BURP Suite - GEN

Burp Suite combines tools for examining and testing web application traffic.

| Component | Role |
| --- | --- |
| Proxy | Intercept and modify traffic between a browser and application |
| [[Tools/GUI Tools/Burp Repeater - GEN\|Burp Repeater]] | Edit and resend messages manually |
| [[Tools/GUI Tools/Burp Intruder - GEN\|Burp Intruder]] | Repeatedly insert payloads into selected request positions |
| [[Tools/GUI Tools/Burp Scanner - GEN\|Burp Scanner]] | Crawl and audit applications where available |
| Decoder | Transform encoded data |
| Comparer | Compare two inputs |
| Sequencer | Analyze token randomness |

Use captured [[Protocols and Notation/HTTP - GEN|HTTP]] traffic to understand entry points during [[Walking an Application]]. Tool availability depends on the edition.
