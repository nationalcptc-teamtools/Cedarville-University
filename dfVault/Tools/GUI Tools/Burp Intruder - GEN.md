# Burp Intruder - GEN

Burp Intruder automates repeated requests with payloads inserted into selected positions. It is part of [[Tools/GUI Tools/BURP Suite - GEN|BURP Suite]].

**Working sequence**
---
1. Start with a representative request.
2. Select the input positions to vary.
3. Configure payload values and the attack type.
4. Review request handling and result settings.
5. Compare results and validate interesting differences manually.

Use it to investigate parameters and input handling during [[API Testing]]. [[Tools/GUI Tools/Burp Repeater - GEN|Burp Repeater]] provides a more controlled manual edit-and-resend workflow.

See [[Burp Intruder - NEW]] for the existing attack-type and session-handling reference.
