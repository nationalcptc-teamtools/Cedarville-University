Google Dorking is a search technique that uses advanced search operators to filter results in such a way to discover sensitive content.

| Filter   | Example           | Description                                               |
| -------- | ----------------- | --------------------------------------------------------- |
| site     | site:example.com  | Returns results only from the specified domain            |
| inurl    | inurl:admin       | Returns results with the specified word in the URL        |
| filetype | filetype:pdf      | Returns results of a specific file type                   |
| intitle  | intitle:admin     | Returns results with the specified word in the page title |
| intext   | intext:password   | Returns results containing the specified word in the body |
| cache    | cache:example.com | Shows Google's cached version of the page                 |
Multiple filters can be combined in a single query. Get more information at this webpage:
https://en.wikipedia.org/wiki/Google_hacking
