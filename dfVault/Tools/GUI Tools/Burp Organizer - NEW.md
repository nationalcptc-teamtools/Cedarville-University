# Burp Organizer

Organizer saves selected HTTP requests and responses for later inspection and annotation.

Send useful messages to Organizer from other Burp tools. Add notes, descriptive labels, and organizational metadata so the purpose and significance of each message remain clear.

## Useful records

- Baseline requests and comparison variants.
- Messages demonstrating a confirmed finding.
- Interesting endpoints requiring follow-up.
- Reproduction details and observations that support reporting.

Open a saved item to inspect its request and response, or send it to another component for further testing. Keep annotations focused on the observation, affected resource, and next action rather than relying on memory.
