# WHOIS

WHOIS retrieves registration information from a directory service. The protocol traditionally uses TCP port 43.

```bash
whois example.com
```

## Useful fields

- Registrar and registration status.
- Creation, update, and expiry dates.
- Authoritative name servers.
- Registrant or administrative contact information when published.
- Referral information directing the client to another registry service.

Contact fields may be redacted or represented by a privacy service. Rate limits and access policies can affect queries. Registration data is a reconnaissance lead rather than proof of current operational ownership or permission to test a system.
